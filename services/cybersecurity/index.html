Questions about cybersecurity

What do you need before a security assessment?

An agreed scope, written authorisation, system ownership details, access arrangements and testing boundaries. The engagement should also define communication channels and how sensitive findings are handled.

Does an assessment certify that a system is secure?

No. An assessment covers an agreed scope at a point in time. Findings and limitations should be documented, and remediation or reassessment can be agreed separately.
